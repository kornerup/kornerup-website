# KORNERUP — Travel & Tourism

**Discover Beyond the Ordinary.**

A premium, responsive, multi-page travel inspiration website.

## Brand
- Industry: Travel & Tourism
- Palette: Midnight Navy `#17243D`, Luxury Gold `#D6B36A`, White `#FFFFFF`
- Language: English
- Style: Modern & Professional

## Pages
Home, Destinations, Journeys, Experiences, About, Contact, FAQ, Privacy Policy, and Terms of Use.

## Getting Started
Open `index.html` in a browser or run `python -m http.server 8000`.

## GitHub Pages
Upload the contents of this folder to the repository root. Go to Settings → Pages → Deploy from a branch → main → / (root).

## Important
This is a demonstration website. Destinations and travel journeys are illustrative, and no live booking, pricing, reservations, or payments are supported. The contact form does not send messages. Photos and fonts load from Unsplash and Google Fonts and require an internet connection.
